# Security and Safety

This is an experimental headlight for a vehicle. A firmware or design fault can do more than leak data: it can blind other road users or leave a rider in the dark. Please report those faults the same way as security issues.

## What to report privately

- Anything that could turn the beam fully off while moving, raise it into oncoming traffic, or defeat thermal protection.
- Ways to pair an unknown Bluetooth device with the head or send it commands.
- Electrical faults that could cause overheating, fire or battery damage.

Ordinary bugs, design questions and build problems go in a normal issue.

## How to report

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Please include what you saw, how to reproduce it, and the firmware version or commit.

Don't open a public issue for these until a fix is available.

## What to expect

This is a hobby project maintained in spare time. Expect an acknowledgement within a week. Fixes go to `main`; there are no supported releases yet.

## Until it's proven

Ride with a backup light. Nothing in this repository has been ride-tested.
